# Changelog

All notable changes to PDFJiff Desktop are documented here.

## [Unreleased]

### Added

- Ordered Images to PDF conversion for JPG, JPEG, JFIF, PNG, and WebP with page layout controls.

- Initial task-first desktop application for Inspect, Compress, Merge, and Capabilities.
- Local in-process PDF processing through the version-pinned public PDFJiff engine.
- Atomic outputs, overwrite protection, input alias detection, size limits, and safety acknowledgements.
